# KADI Facebook, WhatsApp y X Broadcaster

Comunicados ejecutivos, cápsulas informativas y hilos para Facebook, WhatsApp y X, respetando que el canal público de WhatsApp pueda estar deshabilitado.

## Requisitos y notas

- Las rutas de trabajo `%USERPROFILE%\Desktop\RedesSociales\...` son un ejemplo de layout local; ajústalas a tu equipo.

## Marcadores y variables a configurar

| Marcador | Qué poner |
|---|---|
| `<CORREO_VENTAS>` | Correo de ventas público que se usa como CTA mientras WhatsApp esté deshabilitado. |
| `Clínica Fundadora` | Nombre de la clínica de la cohorte fundadora (cliente real en el original). Sustitúyelo por el de tu caso autorizado. |
