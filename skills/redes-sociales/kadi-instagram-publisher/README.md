# KADI Instagram Publisher

Reglas y especificaciones técnicas para Reels 9:16 (1080x1920, 30 fps, H.264/AAC) y carruseles 4:5 (1080x1350), con compuerta de veracidad de claims.

## Requisitos y notas

- Usa `kadi-scene-locked-video` para los Reels y el gate `check-public-claims.mjs` del portal (no incluido; ver el linter de `kadi-redes-sociales`).
- Las rutas de trabajo `%USERPROFILE%\Desktop\RedesSociales\...` son un ejemplo de layout local; ajústalas a tu equipo.

## Marcadores y variables a configurar

Ninguno: la skill no contiene valores personales ni de clientes que debas sustituir.
