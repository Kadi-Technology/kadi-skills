# Video Content Creator

Orquestador de producción de video (documental, promocional o técnico) a partir de grabaciones de pantalla y clips: análisis por subagentes y un script Python ejecutable con moviepy y edge-tts.

## Requisitos y notas

- Se activa con `/Creador.de.contenido [descripción] usando [carpeta] para [plataforma]`.
- `references/` contiene configuraciones por plataforma, componentes Python reutilizables y el catálogo de voces TTS.

## Marcadores y variables a configurar

Ninguno: la skill no contiene valores personales ni de clientes que debas sustituir.

## Credenciales

No requiere credenciales ni API keys. Las voces de `tts_voices.md` son voces estándar de Microsoft Edge TTS.
