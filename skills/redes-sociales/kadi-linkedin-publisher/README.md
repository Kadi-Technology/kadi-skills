# KADI LinkedIn Publisher

Orquestador de artículos técnicos, carruseles PDF y publicaciones B2B para LinkedIn con atribución UTM obligatoria y estado de aprobación por pieza.

## Requisitos y notas

- Depende de los scripts `check-linkedin-growth.mjs` y `check-p01-launch.mjs` del repositorio web de KADI; no se incluyen aquí. Equivalentes de referencia: `skills/redes-sociales/kadi-linkedin-growth-engine/` y el linter de `kadi-redes-sociales`.
- Las rutas de trabajo `%USERPROFILE%\Desktop\RedesSociales\...` son un ejemplo de layout local; ajústalas a tu equipo.

## Marcadores y variables a configurar

Ninguno: la skill no contiene valores personales ni de clientes que debas sustituir.

## Credenciales

No publica por sí sola: ninguna pieza pasa a `published` o `approved` sin evidencia verificada y autorización del PO.
