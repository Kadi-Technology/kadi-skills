# Chrono TTS

Narración asíncrona con ChronoSDK (`chrono speak` y `from chrono import speak`) con caché, muletillas y reproducción desacoplada.

## Requisitos y notas

- ChronoSDK no se incluye en este repo; instálalo antes de usar la skill.
- Se prohíben los comandos crudos de `edge-tts` cuando ChronoSDK está disponible.

## Marcadores y variables a configurar

Ninguno: la skill no contiene valores personales ni de clientes que debas sustituir.

## Credenciales

No requiere credenciales ni API keys.
