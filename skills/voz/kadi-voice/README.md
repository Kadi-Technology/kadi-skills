# KADI Voice

Protocolo de voz sin encimamiento: `chrono speak` siempre con `--blocking`; Salomé para reportes normales y Opus para alertas críticas.

## Requisitos y notas

- Requiere la CLI `chrono` (ChronoSDK) instalada y en el `PATH`; ver `skills/voz/chrono-tts`.

## Marcadores y variables a configurar

Ninguno: la skill no contiene valores personales ni de clientes que debas sustituir.

## Credenciales

No requiere credenciales ni API keys.
